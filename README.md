# SPLITSTEEL — the demo

A standalone copy of the SPLITSTEEL quick start: the whole sitting replayed screen for
screen from the real program, the cards on the table filling in beside it, the objects,
the inheritance layout, and why a split rather than a plate, a passphrase or a multisig.

Generated by `tools/make-demo-site.py` in the main repository; do not edit here.
Every screen is the wizard's own output for the build named on the page. The values are
published test values and must never hold money.
