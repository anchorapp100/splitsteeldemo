# SPLITSTEEL — the demo

A seed backup that is worthless in any one place: the wallet's words become two
random-looking halves, and either half alone says nothing about the seed. This page
replays the whole sitting, screen for screen, exactly as the machine shows it, with
the cards on the table filling in beside the screen, then the objects it leaves
behind, how the halves are placed for heirs, and why a split rather than a plate,
a passphrase or a multisig.

A demonstration for feedback. The values on every screen are published test values
and must never hold money. Nothing here asks for a seed, and nothing ever should.
